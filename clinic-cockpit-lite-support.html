はじめて使う方へ

  1. Windows 11（64-bit）でMicrosoft Storeからアプリをインストールします。
  2. 対応するORCA・UKE形式のCSV/ZIP出力を準備します。元のシステムからの出力操作・権限はご利用者側で確認してください。
  3. アプリでデータを読み込み、対象月・集計結果・前年同月比較を確認します。
  4. 元データに存在しない項目や対象期間は、ゼロと「未取得」を混同しないよう確認してください。

本製品は経営数値の整理・可視化を支援する補助ツールであり、診断・治療・診療報酬の正否を判定する製品ではありません。

よくある質問

ファイルを読み込めません

CSV/ZIPの種類と出力元が対応するORCA・UKE形式か、ファイルが破損していないかをご確認ください。エラーの文面だけでもお問い合わせできます。

数字が合わない・表示されない

対象月、出力範囲、集計に必要な元項目の有無をご確認ください。未取得とゼロは異なります。元データの内容を加工せず照合してください。

Microsoft Storeからインストールできません

Windows UpdateやStore関連サービス、ネットワーク、Microsoftアカウントの状態を確認してください。アプリ自体の不具合とは限りません。

Getting started

  1. Install the application from Microsoft Store on a 64-bit Windows 11 PC.
  2. Prepare compatible CSV/ZIP exports from ORCA/UKE. Confirm your permissions and export steps in the source system.
  3. Import the files in the app, then inspect the period, monthly totals and year-over-year figures.
  4. Distinguish missing source data from an actual zero when reviewing metrics.

This is a business reporting aid, not a diagnostic, treatment or claims-auditing system.

Frequently asked questions

A file will not import

Check whether the CSV/ZIP was exported in a supported ORCA/UKE format and is intact. You can report the error message without attaching data.

A figure is missing or unexpected

Review the reporting period, export range and available source fields. Missing data does not equal zero.

Microsoft Store cannot install the app

Check Windows Update and Store services, your internet connection and Microsoft account. The cause may be outside the app.

Can I ask an external AI about the numbers?

Consultation with external AI is optional and user-directed. Review content to avoid disclosing patient or clinic-confidential information. External AI services are not included.
