まずは無料で確認できます

Windows 11なら、追加アプリを買わなくても「Windows セキュリティ」と「Windows Update」で基本的な状態を確認できます。

  1. スタートメニューで「Windows セキュリティ」を検索して開く。「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」からも開けます。
  2. 「ウイルスと脅威の防止」を見る。現在のウイルス対策の状態や警告を確認します。別のウイルス対策アプリを使っている場合は表示が変わることがあります。
  3. 「ファイアウォールとネットワーク保護」を見る。利用中のネットワークの保護状態を確認します。
  4. 「設定」→「Windows Update」を見る。保留中の更新や再起動の必要性を確認します。

画面や名称はWindowsのバージョン・設定で異なる場合があります。操作に迷ったらMicrosoft公式サポートも参照できます。

Check the basics for free first

Windows 11 includes Windows Security and Windows Update. You do not have to buy an additional app to check these built-in protection settings.

  1. Open Windows Security. Search for “Windows Security” from Start, or find it under Settings → Privacy & security → Windows Security.
  2. Open Virus & threat protection. Check your current protection status and alerts. The display may differ if you use a third-party antivirus product.
  3. Open Firewall & network protection. Check the firewall status for the network in use.
  4. Open Settings → Windows Update. Check whether updates or a restart are pending.

Exact labels may differ across Windows versions. For more help see Microsoft's official Windows support.

Common questions

Is Microsoft Defender free?

Yes. Windows includes built-in security capabilities at no additional charge. Tanuki Security is optional: it makes protection status easier to understand.

Does buying Tanuki Security make my PC safe?

No app can guarantee that. Tanuki Security explains reported protection status; it does not replace antivirus software or remediate infections.

No. Tanuki Security is sold as a one-time purchase and does not require a separate paid antivirus contract to use Windows' built-in features.
