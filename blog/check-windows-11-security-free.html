How to check Windows 11 security for free

You do not have to buy an antivirus subscription just to find out whether Windows is reporting that its protection features are on. Start with the tools already built into Windows 11.

October 23, 2026 · Silent Coast Asset / Project Tanuki
The important distinction: Windows Security and Microsoft Defender Antivirus are included with Windows. The steps below are free. A green status indicator is useful, but does not guarantee that a computer is free of threats.

1. Open the Windows Security app

Open Start, search for Windows Security, and open the app. Its home page summarizes several protection areas. Read any message that says an action is needed before assuming everything is fine.

If your computer is managed by a school or employer, some controls may be set by its administrator. Do not change those policies just to remove a warning.

2. Check which antivirus is active

Choose Virus & threat protection. Review the current-threats area and any displayed recommendations. To find your active antivirus provider, look for Who's protecting me? and select Manage providers if that option is present.

Microsoft Defender Antivirus is built into Windows, but installing another compatible antivirus product can change which provider is active. Seeing Defender shown as inactive does not by itself prove your PC has no antivirus protection. Check the actual provider before making changes.

3. Check the firewall for your current network

Open Firewall & network protection and inspect the status of the active network profile. Windows displays separate network types such as private and public. The firewall filters network traffic; a working browser connection does not replace it.

Do not switch off your firewall as a general troubleshooting shortcut. If a specific application is blocked, investigate the relevant rule instead.

4. Look at protection history

Open Protection history from Windows Security. It can show actions Microsoft Defender took and protection features that need attention. A red item is more urgent than a yellow item; open an individual entry for details rather than judging solely by the color.

If the entry concerns a suspected threat, follow the instructions in the Windows Security app. A plain status-checking tool is not a substitute for a security scan or professional incident response.

5. Check Windows Update

Open Settings → Windows Update and review the update status. Install the appropriate security updates and restart when Windows asks you to, saving your work first. Updates and antivirus status are separate checks: one looking healthy does not prove the other is current.

What if Windows Security shows a warning?

Read the exact wording and the affected section. A yellow warning may be a recommended action or a configuration choice; a red warning may require prompt attention. If you use a third-party antivirus product or a managed work PC, check its own status too. Avoid disabling security settings to make the dashboard appear green.
