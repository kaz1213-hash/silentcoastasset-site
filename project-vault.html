具体的に、何を保存できる？

Project Vaultは、長く続くChatGPT Projectの作業記録を、PCにも保存しておきたい人向けです。

Project全体のVault

現在開いているProjectの会話、JSON、添付ファイルをローカル保存。単体チャットをMarkdownやHTMLなどで保存する機能もあります。

Full → Delta差分バックアップ

Full Vaultを基準に、新規・更新されたチャットをDelta ZIPで保存。対応するFull Vaultがあれば新しい添付ファイルも差分追跡できます。

保存済みVaultの検索

PC上のFull Vault・Delta ZIPを読み込み、複数Projectや保存世代を横断して検索。OpenAI公式エクスポートZIPとの照合や自己診断にも対応します。

What can Project Vault save?

Keep a local record of the ChatGPT Projects you use for long-running work.

Full Project Vault

Save chats, JSON and attachments from the open Project locally. Individual chats can also be saved in formats including Markdown and HTML.

Full → Delta backups

Save new and changed conversations in Delta ZIP archives based on a Full Vault. With a matching Full Vault, newly added attachments can be tracked too.

Search across archives

Load Full Vault and Delta ZIP files on your PC, search across Projects and backup generations, compare with an official OpenAI export ZIP, and run diagnostics.

アカウントのデータをまとめて控えるだけなら、まずOpenAI公式の無料エクスポートを確認してください。Project VaultはProject単位で繰り返し保存し、変更分を管理したい人向けの追加の選択肢です。削除済み会話の復元を保証するものではありません。

プライバシーと利用条件

会話本文・添付ファイル・Vault内容をProject Vaultのサーバーへアップロードする仕組みはありません。ライセンスの有効化・確認にはHTTPS経由でPolarを使いますが、会話内容は送信しません。保存先PCの保護・別途バックアップは必要です。Silent Coast Asset製の独立した拡張機能であり、OpenAI公式製品ではありません。

Get started in three steps

1. Install in Chrome

Install the extension from the Chrome Web Store.

2. Activate your license

Activate the US$10 one-time license key. Installing alone does not unlock paid features.

3. Back up a Project

Open a ChatGPT Project and create a Full Vault; save incremental changes later.

How is this different from the free official export?

If you only need an account-data copy, try OpenAI's free official export first. Project Vault adds repeated Project-level saving, incremental changes and local Vault search. It does not guarantee restoration of deleted chats.

Privacy and requirements

Project Vault does not upload conversation contents, attachments or Vault data to its server. License activation and validation use HTTPS with Polar, without sending conversation contents. Secure and back up your own PC separately. This is an independent Silent Coast Asset extension, not an official OpenAI product.
