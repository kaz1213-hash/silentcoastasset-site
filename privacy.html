1. 運営者 / Operator

Tanuki Site は Silent Coast Asset株式会社（以下「当社」）が提供するソフトウェアです。お問い合わせは support@silentcoastasset.com までお願いします。

2. 基本設計 / Local-first design

Tanuki Site は、ChatGPT上の自然な会話を限定されたサイト作成・変更・Undo指示に変換し、ユーザー端末上のTanuki Siteが再検証してローカルで処理する設計です。サイトの正本データ、履歴、Undo、検証、プレビュー、保存および公開状態は原則としてユーザー端末側が管理します。

The SCA Relay is transport/authentication infrastructure, not a permanent database for the user's website content.

3. Relayが取り扱う情報 / Data handled by the Relay

接続・認証・指示配送・不正利用防止のため、必要最小限の情報を処理します。

  • 匿名化・仮名化されたtenant/project識別子
  • 短い構造化create/revise/Undo指示
  • revision ID、ACK、重複防止メタデータ
  • OAuth / pairing / session情報
  • 購入資格・ライセンス確認に必要なentitlement情報
  • レート制限等に必要な接続元情報
  • MCPのRPC種別、tool名、HTTP status、成功/失敗、処理時間

運用ログには、briefやtool引数、ChatGPT会話全文、Bearer token、購入キー、tenant/project ID、レスポンス本文、内部エラー本文を記録しない設計です。

4. ChatGPT会話 / ChatGPT conversations

当社RelayはChatGPT会話全文を保存することを目的としていません。OpenAI上で入力した情報は、ユーザーとOpenAIとの関係およびOpenAIの規約・プライバシーポリシーにも従います。

5. 購入・ライセンス / Purchase and licensing

初回有効化時、購入・ライセンスキーはRelayを経由してライセンス提供事業者へ送信されます。通常運用では生の購入キーを永続保存せず、ユーザー端末にはRelayが暗号化したopaque refresh credentialを保存する設計です。

refresh時および「この端末のライセンスを解除」実行時には、Relayがそのcredentialを一時的に復号し、ライセンス提供事業者へ必要な検証・deactivation要求を行います。生の購入キーをログ、MCP出力、URL、メールへ出さない設計です。deactivation成功後にのみ端末側資格情報を削除します。

At release, the final policy must name the actual payment/licensing provider and match its live configuration.

6. 保持期間 / Retention

現行実装では、コマンド、OAuth/pairing状態、短命token等を必要最小限の期間だけ保持する設計です。ACK済みまたは期限切れコマンドは有効キューから除外されます。

PUBLICATION BLOCKER: 本番Netlify環境の構造化運用ログ保持期間は未確定です。公開前に実際の保持設定を確認してこの項目を確定します。

7. 外部サービス / Service providers

本番構成では、実際に採用した範囲で OpenAI / ChatGPT、Netlify、Lemon Squeezy 等を利用する予定です。公開版では実際に使う事業者だけを記載します。

8. 利用目的 / Purposes

ChatGPTとの接続、購入資格確認、サイト作成・変更・Undo指示の配送、重複実行や不正利用の防止、セキュリティ維持、障害調査、サービス改善、問い合わせ対応、法令上必要な対応のために処理します。

9. ユーザーのコントロール / User controls

ユーザーはChatGPT連携を利用しないことができます。PC移行時は製品内の「この端末のライセンスを解除」により当該activationを自己解除できる設計です。旧端末が利用不能な場合など、自己解除できないケースのみサポート窓口へお問い合わせください。

10. セキュリティ / Security

データ最小化、短時間token、PKCE、resource/audience binding、one-time code、暗号化credential、レート制限等を実装します。ただしインターネット上の通信・保存について完全な安全性を保証するものではありません。
